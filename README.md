# Aniversário da Mãe

## Visão geral

Este projeto é uma landing page especial criada para celebrar o aniversário de Maria Sueli, com um enfoque emocional, pessoal e festivo. A página foi desenvolvida para reunir informações importantes sobre a comemoração, compartilhar uma mensagem de carinho, apresentar o presente ideal para a aniversariante e facilitar a confirmação de presença dos convidados.

Além disso, o site também funciona como uma forma de homenagem e de contribuição para uma viagem que marcará a celebração dos 43 anos de Maria Sueli e dos 25 anos de casamento com Neilson. A proposta do projeto é transformar a comemoração em uma experiência memorável, com foco em momentos compartilhados e lembranças que ficam para sempre.

---

## O que o site faz

### 1. Apresenta a história e a mensagem do evento
A página inicia com uma apresentação visual elegante, incluindo:
- nome da aniversariante
- frase de homenagem e emoção
- data do evento
- contagem regressiva para o grande dia
- imagem de destaque com o casal

Esse primeiro bloco cria a ambientação da celebração e reforça o caráter pessoal do projeto.

### 2. Informa sobre a festa
A seção de informações da festa mostra:
- local do evento
- endereço
- data e horário
- mapa interativo com a localização usando Google Maps

Com isso, o site funciona como um convite acessível e visualmente bonito para os convidados.

### 3. Apresenta uma lista de experiências como presente
Uma das principais funcionalidades do projeto é a seção de presentes. A página lista diversas experiências que podem ser escolhidas como contribuição, como:
- café especial
- sobremesa em café charmoso
- jantar romântico
- vinho importado
- spa para casal
- transporte para passeio especial
- diária de hotel
- passeios turísticos
- ensaio fotográfico
- contribuição livre em valor escolhido

Cada item aparece em um card com imagem, título e valor, e ao clicar é possível gerar um código PIX para a contribuição.

### 4. Permite confirmação de presença
Também há um formulário de confirmação de presença onde os convidados podem:
- informar o nome completo
- indicar se irão comparecer
- responder se levarão acompanhantes
- escrever o nome dos acompanhantes, se houver
- deixar uma mensagem para a aniversariante

A submissão é feita por e-mail, utilizando uma integração com o FormSubmit.

### 5. Gera uma experiência interativa e personalizada
Os elementos interativos do site incluem:
- contagem regressiva em tempo real
- cards de presentes com botões de ação
- modal para confirmação do presente
- envio de dados do formulário sem necessidade de backend

Isso torna o projeto mais envolvente e funcional para a ocasião.

## Integrações e tecnologias usadas

### Front-end
- HTML5
- CSS3
- JavaScript puro

### Estilização e identidade visual
- fontes externas do Google Fonts
- paleta de cores suave com destaque para azul e branco
- layout responsivo e visual elegante para celular e desktop

### Integração de envio de e-mails
- FormSubmit: usado para processar o formulário de confirmação de presença e também para registrar a intenção de presente

### Mapa e localização
- Google Maps embed: incorporado na página para mostrar o endereço do evento

### Conteúdo visual
- imagens locais armazenadas na pasta assets
- fotos e ícones organizados por categoria para compor a experiência visual

---

## Observações importantes

- O projeto é estático, sem backend ou banco de dados.
- A lógica de envio de e-mail depende de serviços externos, como FormSubmit.
- A integração do PIX é feita por link externo, em vez de um processamento financeiro direto no site.
- O objetivo principal do site é emocional e comemorativo, sendo mais uma experiência de celebração do que uma aplicação tradicional.

---

## Conclusão

Este site foi criado para celebrar uma data muito especial da família, unindo elegância visual, mensagem afetiva e funcionalidade prática. Ele organiza a mensagem da festa, centraliza as informações do evento, facilita a confirmação de presença e transforma a lista de presentes em uma experiência íntima e divertida.

Em resumo, o projeto funciona como um convite virtual de aniversário com interação, carinho e foco na memória compartilhada.
